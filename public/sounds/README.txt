# Fichier Audio de Notification Tivo

Déposez votre fichier audio ici pour personnaliser le son de notification de l'application :

Formats acceptés :
- notification.mp3 (recommandé)
- notification.wav
- notification.ogg

Nom attendu par défaut :
notification.mp3

Emplacement complet :
c:\Users\nabna\Desktop\TIVO\public\sounds\notification.mp3

Note : Vous pouvez également charger directement votre fichier audio depuis l'interface de l'application dans les Paramètres de notifications (icône cloche -> Paramètres -> "Choisir mon fichier audio").
